# capicom-msxml5
Script em batch (.bat) para instalação e registro das bibliotecas legadas CAPICOM.DLL, MSXML5.DLL e MSXML5R.DLL no Windows. Projeto desenvolvido em parceria com a Sabe Sistemas, com objetivo de facilitar a configuração de ambientes onde essas DLLs são necessárias para o correto funcionamento do sistema de emissão de notas fiscais.
